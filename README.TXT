
# IMAZE - Image Search Website

Welcome to the Imaze project repository! This README is a guide for contributors and developers to understand the structure, functionality, and deployment process of Imaze, our innovative image search website.

## Overview
Imaze is designed to provide users with a smooth and efficient way to search for images across various categories. It combines clean design with powerful functionality, offering users the ability to explore, view, and download images seamlessly. With its easy-to-use interface, Imaze caters to diverse audiences seeking visual content for personal or professional use.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** JavaScript (APIs for image fetching)
- **Deployment:** Netlify, Heroku

## Structure
The website follows a straightforward and user-friendly structure, consisting of the following pages:
1. **Home** - The landing page, offering a welcoming introduction to the image search engine.
2. **Gallery Pages** - Dedicated sections for different categories (e.g., nature, architecture) with dynamically fetched and displayed images.
3. **Search** - An intuitive search bar to allow users to find specific images.
4. **Image Details** - Detailed views with options for downloading images.
5. **Login/Register** - User authentication for personalized access.
6. **Contact Us** - A page where users can reach out for support or feedback.

## Key Features
- **Responsive Design:** Imaze is fully responsive, offering an optimal experience on all devices, from desktop to mobile.
- **Download Functionality:** Users can directly download images from the site.

- **Smooth Navigation:** User-friendly navigation with a well-structured navbar.

## Deployment
Imaze is deployed on:
1. **Netlify** - Primary deployment for fast and secure web hosting.
2. **Heroku** - For backend services and dynamic content management.
